## 41. CLI

### Server

```bash
go run cmd/server/main.go
```

Starts the central monitoring server and exposes the API/WebSocket services.

### Probe

```bash
go run cmd/probe/main.go
```

Starts a monitoring probe, registers it with the central server, executes monitoring tasks, and reports measurements.

### Migration

```bash
go run cmd/migrate/main.go up
go run cmd/migrate/main.go down
```

Applies or rolls back database migrations.

### Tool Management

```bash
go run cmd/tools/main.go list
go run cmd/tools/main.go list --installed
go run cmd/tools/main.go list --category icmp
go run cmd/tools/main.go check
go run cmd/tools/main.go install --generate --script x.sh
go run cmd/tools/main.go execute --tool mtr google.com
go run cmd/tools/main.go info --tool traceroute
```

Provides tool discovery, dependency checking, installation-script generation, execution, filtering, and tool information.
