NetMon - Complete Capabilities Overview

🎯 What NetMon Can Do (As of 2026-09-11T05:08:55.468Z)

NetMon is a production-grade distributed network monitoring platform with comprehensive capabilities for monitoring hosts, routers, switches, servers, ISPs, and entire network infrastructure.

- ✅ Central Server - Coordinates all monitoring operations

- ✅ Load Distribution - Distribute monitoring tasks across probes

Time-Series Data Storage

🔧 Built-In Monitor Types (10 Types)

1. ICMP Monitor (monitors/icmp.go)

What it does:
- Ping targets with configurable count and packet size
- Measure latency (min/avg/max), packet loss, jitter
- IPv4 support with privileged mode for Windows
- Statistical analysis of RTT samples

Use cases:
- Basic reachability testing
- Latency baseline monitoring
- Network quality assessment
- SLA compliance verification

2. TCP Monitor (monitors/tcp.go)

What it does:
- TCP port connectivity testing
- DNS resolution time measurement
- TCP connection time tracking
- Optional throughput measurement
- TCP retransmission detection (platform-specific)

Use cases:
- Service availability monitoring (web, database, SSH)
- Port reachability testing
- Connection performance analysis
- Application response time

3. UDP Monitor (monitors/udp.go)

What it does:
- UDP throughput measurement
- Packet loss calculation
- Latency tracking for acknowledged packets
- Configurable packet size and count

Use cases:
- VoIP quality monitoring
- Video streaming performance
- Game server latency
- UDP-based service testing

4. DNS Monitor (monitors/dns.go)

What it does:
- DNS query resolution (A, AAAA, MX, NS, TXT, SOA, PTR)
- Query time measurement
- Multiple record type support
- Resolver comparison

Use cases:
- DNS server performance
- DNS propagation verification
- Resolver health monitoring
- DNS-based service discovery testing

5. HTTP/HTTPS Monitor (monitors/http.go)

What it does:
- Full HTTP timing breakdown (DNS, connect, TLS, TTFB, total)
- TLS certificate validation and inspection
- Certificate expiration tracking
- Custom headers and methods
- Redirect following
- Response size measurement
- TLS version and cipher detection

Use cases:
- Web service monitoring
- API endpoint testing
- SSL certificate monitoring
- CDN performance analysis
- HTTP vs HTTPS comparison

6. Traceroute Monitor (monitors/traceroute.go)

What it does:
- Hop-by-hop path discovery
- Per-hop latency measurement
- MTU detection (binary search with DF flag)
- AS path construction (with external ASN lookup)
- Route change detection
- IPv4 support

Use cases:
- Network path analysis
- Routing issue diagnosis
- ISP path verification
- Network topology mapping

7. SNMP Monitor (monitors/snmp.go)

What it does:
- SNMP device polling
- OID-based metric collection
- Device statistics gathering

Use cases:
- Router/switch monitoring
- Device health tracking
- Interface statistics from SNMP-enabled devices

8. Bandwidth Monitor (monitors/bandwidth.go)

What it does:
- HTTP-based download speed testing
- HTTP-based upload speed testing
- Configurable test duration and sample size
- Bidirectional or single-direction testing

Use cases:
- ISP bandwidth verification
- Link capacity testing
- CDN performance measurement
- Network bottleneck identification

9. Connectivity Monitor (monitors/connectivity.go)

What it does:
- IPv4 connectivity testing (default: 8.8.8.8)
- IPv6 connectivity testing (default: 2001:4860:4860::8888)
- Per-protocol latency measurement
- Configurable test endpoints
- TCP with ICMP fallback

Use cases:
- Dual-stack deployment verification
- IPv4 vs IPv6 performance comparison
- Internet connectivity monitoring
- Resolver reachability testing

10. Interface Monitor (monitors/interface.go)

What it does:
- Network interface statistics collection
- RX/TX error tracking
- RX/TX packet drop monitoring
- Byte and packet counters
- Platform-specific implementations (Linux/Windows/macOS)

Use cases:
- Interface health monitoring
- Error rate detection
- Packet loss root cause analysis
- Hardware issue identification
